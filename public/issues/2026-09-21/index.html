01 · Image generation / ComfyUI

Qwen-Image 2.1 adds native transparency and ten-reference editing, with day-one ComfyUI support.

Qwen released Qwen-Image 2.1 on September 20 with a 7B visual-generation component, native 2K output and one pipeline for text-to-image and image editing. It can generate RGBA images with transparency, accept up to ten reference images, and target local edits with circles, painted annotations or masks.

ComfyUI, Diffusers, vLLM-Omni and SGLang all shipped support at launch. The main constraint for working artists is licensing: the Qwen Research License permits non-commercial use only unless a separate commercial licence is obtained.

Why it mattersTransparent output and multi-reference editing are directly useful for concept, design and prep work, and native ComfyUI support removes the usual wait for community integration. The research-only licence means it should not quietly slide into paid client or studio work without a licensing check.

02 · MiniMax H3 / ComfyUI

MiniMax H3 SPEED V2 trades early resolution for faster ComfyUI drafts.

StanLukuvka’s H3 SPEED sampler starts denoising on a cheaper low-resolution grid and raises resolution as the denoise progresses. Version 2 adds Euler, Heun, DPM2, Exp Heun 2 X0 and RES Multistep support, makes its calibration sampler-aware, and fixes repeated resizing that could soften image-to-video keyframes.

In the author’s single 10-second, roughly 0.5-megapixel test clip, a conservative three-stage setup cut a 571-second Euler run to 439 seconds; an aggressive four-stage setting reached 238 seconds but showed strong artifacts. Those numbers are project benchmarks rather than independent tests, and the node is licensed for non-commercial use.

Why it mattersThis is useful for iteration rather than final-quality rendering: the conservative settings can shorten H3 draft loops without changing the model or retraining it. The supplied evidence makes the quality-versus-speed tradeoff visible instead of hiding it behind one headline number.

03 · Higher education / Canada

Canada’s national AI-literacy course becomes available to post-secondary institutions today.

Beginning September 21, Canadian colleges and universities can join the National Student AI Literacy Initiative consortium and offer students a free three-hour course on practical, responsible AI use and workplace readiness. The federal partnership with Amii is intended to reach up to one million post-secondary students.

The first complete chapter of the separate Essentials for Educators stream also becomes openly available today, with five more chapters planned through the fall.

Why it mattersThis gives Canadian programs a no-cost baseline for general AI literacy instead of asking every department to rebuild the same introductory material. Discipline-specific programs can then spend more time on production practice, critique, ethics and assessment.

04 · Agent security

Plugin4Shell exposes a supply-chain gap in coding-agent plug-ins.

AIR Security disclosed a SHA-pinning bypass in the plug-in update paths used by Claude Code, OpenAI Codex, GitHub Copilot and Gemini CLI. The flaw can let a repository owner substitute different code for the commit a marketplace believes it pinned; background updates make the attack zero-click in configurations that auto-update plug-ins.

Anthropic patched Claude Code in 2.1.179 and OpenAI patched Codex in 0.146.0. At disclosure, AIR reported no Microsoft patch for Copilot, while Google had deprecated Gemini CLI and directed users toward Antigravity; AIR also said it had seen no in-the-wild exploitation.

Why it mattersCoding agents often inherit shell, repository and credential access, so plug-in provenance now deserves the same scrutiny as packages and CI actions. Anyone using agent plug-ins on production code should verify patched versions and treat automatic extension updates as part of the software supply chain.

05 · Adobe Firefly / Video

Firefly adds clip-wide background removal and reference images for Kling 3 Omni.

Adobe’s September Firefly update can automatically detect a subject and remove the background across an entire video clip instead of requiring frame-by-frame masking. The same update adds reference-image input for Kling 3.0 Omni, expands GPT Image 2 from three to ten aspect ratios in web generation and Boards, and raises prompt-length limits for image and video generation on the web.

Why it mattersFor previs, pitch work and rough composites, clip-wide isolation removes a common setup step before generative or editorial work begins. For final VFX, the output still needs to be judged like any automated matte, especially around motion blur, hair and transparency.

A 3D camera-path node turns MiniMax H3 moves into editable keyframes

NyckM’s Camera H3 node provides an orbit/elevation/distance interface and timeline, then compiles the path into H3 prompts and options. It is prompt-level guidance rather than a geometry adapter, so angle and timing can still drift.

Viggle Meridian publishes ComfyUI LoRAs for geometry-guided re-camera work

Meridian uses MiniMax H3 plus VGGT-Omega geometry to re-observe existing footage from a new camera path. The current reference implementation expects a high-memory CUDA GPU, and its weights and geometry components carry separate geographic and non-commercial licence restrictions.
