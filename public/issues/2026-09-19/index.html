01 · Blender / spatial capture

Blender 5.3 brings 3D Gaussian Splats into the core pipeline.

Blender 5.3’s current alpha adds native import and rendering for 3D Gaussian Splats, removing the need for a third-party add-on just to get captured splat data into a scene. Current builds can import PLY and SPZ splats and render them across Blender’s engines; Blender’s 5.3 pipeline notes also add USD support for the Gaussian-splat schema.

This is still an alpha feature: export is not there yet, performance needs work, and current builds have known color-space and transform limitations.

Why it mattersGaussian splats are becoming a practical bridge between location capture, photogrammetry, previs and virtual production. Native support means a captured environment can live closer to ordinary Blender layout, lighting and camera work instead of sitting in a separate specialist tool—but this is a feature to test now, not lock into a production pipeline yet.

02 · Local / open AI

Bonsai 2 puts a 27B multimodal model into a 5.95 GB local footprint.

PrismML released Ternary Bonsai 2 27B, a Qwen3.8-27B-derived model packed into ternary weights. The PTQ1_0 language model is 5.95 GB, keeps a 262K context window, offers an optional vision tower, and is Apache 2.0 licensed.

PrismML reports 98.2% of its FP16 benchmark average at roughly one-ninth the storage footprint, but those are vendor benchmarks. The biggest practical caveat is runtime support: the new packing currently requires PrismML’s llama.cpp fork rather than stock llama.cpp.

Why it mattersThis is exactly the direction that makes local assistants more useful to artists: larger reasoning models without 50+ GB weight files. If the quality claims hold up in real creative-agent and coding tasks, models like this could make private, offline assistants on ordinary workstations far more practical; the custom runtime is the part to watch before building around it.

03 · Games / education

Generative AI is now routine for most surveyed Japanese game developers.

CESA’s September 17 preview of its 2026 Game Industry Report says 85.8% of surveyed game developers use generative AI for work. CESA also says human review, correction and supervision were the most common governance measures, alongside restrictions on approved tools and policies against using raw generated output unchanged.

The full report is due in early December, so the preview is more useful as a directional industry signal than as a complete picture of which tasks and tools are winning.

Why it mattersFor game-development education, the important lesson is not simply “teach prompting.” AI literacy is rapidly becoming normal production literacy, while verification, rights awareness, tool policy and human review are becoming part of the same skill set. That is a curriculum change, not just a software trend.

04 · Coding agents

Copilot code review is turning into a multi-agent validation workflow.

GitHub’s September 18 Copilot update expands code review beyond comments: subsequent reviews can resolve feedback that has already been addressed, suggest commit messages for applied fixes, and use shell tools to validate changes. GitHub is also combining findings from multiple agents in Lite reviews and rolling out efficiency, balance and intelligence tiers for automatic model selection.

The same weekly release adds more agent workflow support in VS Code, including local Dev Containers and pull-request creation from Agent Host sessions.

Why it mattersThe useful shift is from “AI writes code” to “AI participates in the review-and-verification loop.” For game tools, pipeline scripts and student projects, that makes it more important to teach agents alongside tests, source control and reproducible environments rather than treating code generation as a standalone trick.

05 · AI business / models

Anthropic is reportedly weighing another model release as the AI race accelerates.

Reuters reports that Anthropic is considering releasing a new model ahead of a potential IPO as competitive pressure from OpenAI and fast-moving open models increases. No new model has been formally announced, so this is a watch item rather than a product release.

The more durable signal is the release cadence: the major labs increasingly have to improve models, agent capabilities and product integration at the same time instead of treating model launches as occasional platform events.

Why it mattersCreative tools are increasingly built on top of general-purpose models through APIs, MCP and agent layers. Faster model turnover can improve those tools quickly, but it also makes vendor lock-in, reproducibility and model-specific workflows more fragile—another reason to keep workflows modular and benchmark the task rather than the brand.
