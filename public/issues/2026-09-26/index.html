Today’s five

Ordered by practical value.

01 · ComfyUI / video

Sonder Editor 0.7 puts a real timeline inside ComfyUI.

Sonder Editor adds a multi-track timeline, reusable character and location references, prompt sections, guide frames, render queues and retakes to ComfyUI. Version 0.7 landed September 25 and keeps the generation work in your existing graph.

Why it mattersThis makes long-form local video work easier to manage. H3, LTX and Wan can all sit behind the same editing surface.
GitHub
02 · MiniMax H3 / VFX

A new H3 LoRA pack adds VFX editing and style transfer.

Alissonerdx’s new MiniMax H3 pack includes LoRAs for prompt-driven VFX edits, style transfer, sharpness recovery and an experimental head swap. The repo includes ComfyUI workflows and example clips.

Why it mattersThe VFX Edit model is aimed at changing one part of an existing shot while keeping the motion and framing. That is more useful for production than regenerating the whole clip.
Hugging Face
03 · Editing / Resolve

Runway now works inside DaVinci Resolve Studio.

Runway’s new Resolve plugin can generate images and video, restyle selected footage and place the result back on the timeline. Edit Studio can use up to five keyframes to guide a re-render of an existing shot.

Why it mattersIt removes the export-upload-download loop. AI video work can now happen inside a normal edit instead of in a separate browser workflow.
Runway
04 · Texturing / Mari

Mari 8 Beta 2 adds better tiling and A/B material checks.

Mari 8’s second open beta adds Tri-Planar Tiled and Hex Tile nodes, plus more than 50 Node Graph additions. It also adds wipe-style A/B comparisons so artists can check material variants without rebuilding the graph.

Why it mattersThe new tiling tools are useful for scanned and procedural materials, especially on assets with awkward UVs or visible repetition.
CG Channel
05 · Rendering / Octane

Octane’s latest alpha can turn SDFs into meshes.

OctaneRender 2027.1 Alpha 3 can bake SDF geometry into polygon meshes for scattering and physics. It also improves the real-time neural renderer, MaterialX support and OCIO 2.5 compatibility.

Why it mattersSDF-to-mesh baking gives procedural shapes a path into simulation and other mesh-only tools. OTOY says this is an experimental build, not a production release.
OTOY release notes
